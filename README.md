# ЭБУ hex-тренажёр

Hex-редактор для чтения прошивок ЭБУ и разметки калибровок. Открывает
готовые DAMOS (`.dam`) и A2L как эталон, позволяет собрать свой маппак и
сохранить его в тех же форматах, а потом сверить свою разметку с эталоном.

Ghidra остаётся отдельно: адреса здесь те же, что в Ghidra при загрузке
образа как Raw Binary с той же базой (Base Address), и те же, что в DAMOS/A2L.

Только чтение: байты прошивки не меняются.

## Запуск

Откройте `trainer/index.html` в Chrome, Edge или Firefox. Установка и
сервер не нужны, файлы никуда не отправляются.

## Как работать

1. **Прошивка…** — открыть `.bin` (или перетащить в окно).
2. **Эталон DAMOS / A2L…** — загрузить эталон. База образа подбирается
   сама: какая база укладывает объекты эталона в файл и при какой счётчики в
   заголовках карт совпадают с DAMOS. Если в Ghidra у вас другая база, её
   можно оставить, а сдвинуть адреса эталона.
3. Эталон виден двумя способами: подчёркиванием в hex и списком на вкладке
   «Эталон». Для тренировки его можно **скрыть** — тогда он молчит до сверки.
4. **Свой маппак**: встаньте на начало карты (или выделите её байты) и нажмите
   `M`. Задаются вид (значение, кривая, карта, ось, блок, строка), раскладка
   (сразу данные или заголовок Bosch со счётчиками и осями), размер, ячейка,
   пересчёт в физические единицы и оси. Таблица с осями видна прямо в окне.
   Внизу — «сетка у курсора»: любые байты как таблица заданной ширины и
   профиль значений; так ищутся карты без заголовка.
5. **Мой маппак → Сохранить как A2L / DAMOS** (`Ctrl+S` / `Ctrl+Shift+S`).
   Сохранённый файл открывается обратно как маппак или как эталон.
6. **Сверка** — пара ищется по адресу (имя может быть своим). Для каждой пары
   видно, что сходится и что нет: адрес (в том числе «размечено тело без
   заголовка»), вид, размер (в том числе «строки и столбцы перепутаны»),
   ячейка, пересчёт, оси. Пропущенные объекты эталона скрыты, пока не
   попросите.

Маппак автоматически сохраняется в браузере для каждой прошивки (по CRC32).

## Горячие клавиши

| Клавиша | Действие |
|---|---|
| стрелки, PgUp/PgDn, Home/End | курсор; с Shift — выделение (или тянуть мышью) |
| `G`, `Ctrl+G` | перейти: адрес, `+смещение` в файле или имя объекта |
| `]` / `[` | следующий / предыдущий объект (свой или эталона) |
| `Alt+←` / `Alt+→` | назад / вперёд по переходам |
| `M` | новый объект у курсора или по выделению; на своём — изменить |
| `Enter`, двойной щелчок | открыть объект под курсором |
| `Del` | удалить свой объект под курсором |
| `-` / `+` | сетка у курсора: уже / шире |
| `Ctrl+F`, `F3` | поиск байтов (`??` — любой) или текста cp1251 |
| `Ctrl+Z` / `Ctrl+Y` | отменить / вернуть |
| `Ctrl+S` / `Ctrl+Shift+S` | сохранить маппак как A2L / DAMOS |
| `Ctrl+O` | открыть прошивку |

## Соглашения о картах

Строки и столбцы считаются **по памяти**: столбцы — быстрый индекс (соседние
ячейки), строки — медленный. Так сравнение не зависит от того, что в DAMOS и
A2L называется X и Y:

- в DAMOS ось X — это строки, Y — столбцы;
- в A2L при `COLUMN_DIR` быстрее меняется Y, при `ROW_DIR` — X;
- в заголовке Bosch сначала счётчик строк, потом столбцов, затем ось строк и
  ось столбцов; счётчики — слова, только если обе оси словные.

Последние два факта проверены на `px5ns03d.dam` и его образе: порядок
заголовка — на всех неквадратных картах, ширина счётчиков — на всех картах с
заголовком.

Что DAMOS выразить не может (big-endian, float, двумерный блок, другой
порядок заголовка), при сохранении перечисляется в замечаниях, а не
теряется молча.

## Тесты

```
node tests/run.js
```

Синтетическая прошивка с известными картами: запись в A2L и DAMOS и чтение
обратно, сверка (верная, транспонированная, без заголовка), подбор базы.
Если рядом лежит настоящая пара DAMOS + образ (репозиторий Ivanbl4 по
соседству или переменные `DAMOS=… BIN=…`), все её объекты проходят круг
через A2L и через DAMOS: на `px5ns03d.dam` это 2447 из 2447 без расхождений.
