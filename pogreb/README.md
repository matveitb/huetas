# Контроллер погреба и гаража

ESP32 + SIM800L. Держит в погребе +2…+4 °C тепловой пушкой с ТЭНом (с продувкой
кулером перед выключением), проветривает гараж по точке росы, присылает тревоги
и отчёты по SMS и принимает SMS-команды. Схема подключения — на странице
«Контроллер погреба».

## Что в папке

| Файл | Что делает |
|---|---|
| `firmware/pogreb/pogreb.ino` | основной скетч: датчики, управление, тревоги, команды |
| `firmware/pogreb/config.h` | **настройки: номер телефона, плата, пины, пороги** |
| `firmware/pogreb/logic.*` | термостат пушки, вытяжка по точке росы, тревоги |
| `firmware/pogreb/modem.*` | SIM800L: SMS кириллицей, приём команд, время сети |
| `firmware/pogreb/pdu.*`, `textutil.*` | кодирование SMS (UCS2, длинные сообщения) |
| `firmware/pogreb/commands.*` | разбор SMS-команд |
| `firmware/pogreb/sht31.*` | драйвер датчиков SHT31/SHT30 |
| `tests/` | тесты логики на компьютере |

## Прошивка

1. Arduino IDE → Настройки → «Дополнительные ссылки для менеджера плат»:
   `https://espressif.github.io/arduino-esp32/package_esp32_index.json`.
   Менеджер плат → установить **esp32** (подходят версии 2.x и 3.x).
2. Менеджер библиотек → установить **OneWire** и **DallasTemperature**.
3. Открыть `firmware/pogreb/pogreb.ino`.
4. В `config.h`:
   - вписать свой номер в `OWNER_PHONES` (формат `+7XXXXXXXXXX`);
   - `BOARD_TCALL 0` — ESP32 DevKit + отдельный SIM800L, `1` — LilyGO T-Call;
   - если не ставили делитель на аккумулятор — `HAS_VBAT_DIVIDER = false`.
5. Плата: **ESP32 Dev Module** (для T-Call — **ESP32 Wrover Module**). Порт — свой. Загрузить.

## Первый запуск

1. Откройте монитор порта на 115200. Команды можно вводить прямо там — так удобно
   проверять всё на столе без SIM-карты.
2. Назначьте датчики DS18B20: команда `датчики` покажет список с температурами.
   Зажмите один датчик в руке, повторите `датчики` — тот, что нагрелся, ваш.
   Затем: `датчик погреб 1`, `датчик пушка 2`, `датчик кузов 3`. Назначение
   сохраняется в памяти.
3. Вставьте SIM-карту и отправьте с телефона `тест` или `статус`.
4. Первый раз проверяйте **с лампой вместо пушки**: `обогрев вкл` — лампа горит,
   `обогрев авто` — после минимального времени работы гаснет, кулер продувает.

## SMS-команды

Регистр не важен, «ё» можно писать как «е».

| Команда | Что делает |
|---|---|
| `статус` | всё сразу: погреб, пушка, гараж, улица, кузов, вытяжка, 220 В, аккумулятор |
| `отчет` | короткий отчёт (такой же приходит каждый день в 9:00) |
| `тест` | прислать тестовое SMS |
| `стоп` | выключить всё: пушку (с продувкой) и вытяжку. Сохраняется после перезагрузки |
| `пуск` | вернуть автоматику, снять блокировку после тревоги |
| `обогрев вкл` / `выкл` / `авто` | ручное управление пушкой (вкл — на один цикл, защиты работают) |
| `вытяжка вкл` / `выкл` / `авто` | ручное управление вытяжкой |
| `цель 3` | цель в погребе, °C: пушка включается ниже 2,0 и выключается выше 3,5 |
| `датчики` | список DS18B20 с температурами |
| `датчик погреб 1` | назначить датчик (роли: погреб, пушка, кузов) |
| `перезагрузка` | перезапустить контроллер |
| `помощь` | список команд |

SMS с номеров не из `OWNER_PHONES` игнорируются.

## Как работает

**Погреб.** Пушка включается ниже «цель − 1» и выключается выше «цель + 0,5»,
но работает не меньше 5 минут и не чаще одного включения в 5 минут. Перед
выключением включается кулер, пушка гаснет, а кулер дует, пока выход не остынет
ниже 40 °C (от 2 до 10 минут; без датчика на выходе — 3 минуты). Температуру
берёт с DS18B20 в погребе, если его нет — с SHT31.

**Защиты пушки:**
- перегрев на выходе выше 85 °C — выключить с продувкой, пауза 30 минут, SMS;
- больше 2 часов без перерыва — пауза 15 минут, SMS;
- нет показаний температуры погреба — выключить, SMS;
- выше 25 °C в погребе или 110 °C на выходе — считается пожаром: выключается
  всё, включая кулер, и ничего не включится до команды `пуск`.

**Гараж.** Вытяжка включается, когда в гараже влажнее 60 % **и** точка росы на
улице ниже, чем в гараже, на 3 °C (воздух снаружи суше). Выключается, когда
разница меньше 1 °C или влажность ниже 55 %. В мороз сильнее −20 °C работает не
больше 10 минут в час.

**SMS-тревоги:** холодно (< +0,5 °C) или жарко (> +8 °C) в погребе; пушка не
греет; греет час, а теплее не стало; выключена, а на выходе горячо (залипло
реле?); отказ любого датчика; датчики в погребе расходятся; сухо в погребе
(< 80 %); риск конденсата на машине (кузов холоднее точки росы + 1 °C); сыро в
гараже 12 часов; пропало и вернулось 220 В; садится аккумулятор. После
перезапуска приходит SMS с причиной (включение, сбой, сторожевой таймер).

Каждый день приходит отчёт со временем работы пушки и расходом в кВт·ч
(мощность пушки задаётся в `config.h`).

## Тесты на компьютере

```sh
g++ -std=c++17 -o test_logic tests/test_logic.cpp firmware/pogreb/logic.cpp \
    firmware/pogreb/textutil.cpp firmware/pogreb/pdu.cpp firmware/pogreb/commands.cpp
./test_logic
```

Проверяются термостат и продувка, все защиты пушки, вытяжка, тревоги, точка
росы, кодирование SMS и разбор команд. Код, работающий с железом, проверен
компиляцией с заглушками Arduino (`tests/stubs`), но на настоящем ESP32 его
нужно собрать в Arduino IDE.
