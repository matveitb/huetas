# Разметка MD22 v159 (53423-A03, 2025-04-11): первый проход

Прошивка: `md22v159_53423-A03_16_2025-04-11.bin` (0xD0000 байт, из архива в корне).
Процессор: семейство Infineon C166 / XC2000. Вектор сброса `JMPS 0xC0,0x0298`, файл отображается с адреса 0xC00000.

## Карта памяти

| Адреса            | Что там                                                         |
|-------------------|-----------------------------------------------------------------|
| C00000–C07FFF     | Загрузчик (`AEC 07.07.000`, сервисный монитор)                  |
| C10000–C5BFFF     | Основная программа (`AEC 07.07.159`, сборка 27.03.2025)         |
| C70000–C77FFF     | Вспомогательный код/данные                                      |
| **C80000–C87FFF** | **Калибровка** (ID `md22v159_53423-A03_16_2025-04-11` по C852AE) |
| CC0000–CCFFFF     | В основном нули, вероятно, эмуляция EEPROM / адаптации          |

## Таблицы

`candidates.tsv` содержит кандидатов, найденных эвристикой по гладкости данных.
Границы приблизительные (первая строка иногда захватывает соседний параметр
или ось), назначение таблиц пока не определено.

Наиболее надёжные 2D-таблицы 16×16: C82AF4 (u16), C82E98 (u16), C84B78 (u8),
C868C8 (u16), C87500 (u8), C87A6E (u16).

## Запуск

    python3 tools/blocks.py   <bin>                 # карта областей по энтропии
    python3 tools/find_maps.py <bin>                # поиск таблиц в калибровке
    python3 tools/dump.py     <bin> C84B78 256 16   # дамп: адрес, длина, ширина строки
