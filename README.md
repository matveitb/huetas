# ЭБУ hex-тренажёр

Hex-редактор для чтения прошивок ЭБУ и разметки калибровок в духе WinOLS.
Открывает готовые DAMOS (`.dam`) и A2L как эталон, позволяет собрать свой
маппак и сохранить его в тех же форматах, сравнить две версии прошивки и
сверить свою разметку с эталоном.

Ghidra остаётся отдельно: адреса здесь те же, что в Ghidra при загрузке
образа как Raw Binary с той же базой (Base Address), и те же, что в DAMOS/A2L.

Только чтение: байты прошивки не меняются.

## Запуск

Откройте `dist/ecu-hex-trainer.html` (всё в одном файле) или
`trainer/index.html` в Chrome, Edge или Firefox. Установка и сервер не нужны,
файлы никуда не отправляются. Однофайловая сборка обновляется командой
`python3 tools/build_single.py`.

## Интерфейс

Устроен как WinOLS: сверху меню (Проект, Правка, Вид, Выделение, Поиск,
Эталон, Справка) и панель инструментов, слева окно «Карты», в центре вкладки —
hex-дамп и открытые карты, справа значения под курсором, внизу строка
состояния (адрес, смещение, значение, карта под курсором, база).

Окно «Карты» — таблица с колонками имя, адрес, размер, тип (сортируется по
щелчку на заголовке) и вкладками внизу: **Мой маппак**, **Эталон**,
**Отличия**, **Сверка**. Щелчок по строке ведёт в hex, двойной открывает карту.

## Как работать

1. **Проект → Открыть прошивку** (`Ctrl+O`) или перетащить `.bin` в окно.
2. **Эталон → Открыть DAMOS / A2L**. База образа подбирается сама: какая база
   укладывает объекты эталона в файл и при какой счётчики в заголовках карт
   совпадают с DAMOS. Если в Ghidra у вас другая база, её можно оставить, а
   сдвинуть адреса эталона. Эталон подчёркнут в hex и перечислен во вкладке
   «Эталон»; для тренировки его можно **скрыть** — тогда он молчит до сверки.
3. **Поиск карт.** Основной вид — таблица из N столбцов ячеек выбранного
   формата (8/16/32 бит или float, со знаком, LoHi/HiLo, hex/dec); обычный
   hex — 16 столбцов по байту. `M` и `W` подбирают ширину, пока карта не
   встанет ровной таблицей; `Tab` переключает **текст → 2D → 3D**: в 2D те же
   байты рисуются графиком с линией через каждые N ячеек (у карты линии
   параллельны «скачкам»), в 3D — поверхностью выделения. `A` начинает строки
   с курсора, и карта встаёт с первого столбца.
4. **Свой маппак.** Выделите карту и нажмите `K` — ширина и формат ячейки
   подставятся из вида. Задаются вид (значение, кривая, карта, ось, блок,
   строка), раскладка (сразу данные или заголовок Bosch со счётчиками и осями),
   размер, ячейка, пересчёт в физические единицы и оси.
5. **Окно карты.** `Enter` или двойной щелчок открывает карту во вкладке:
   текст (таблица с осями), 2D (строки линиями), 3D (вращается мышью).
   Стрелки ходят по ячейкам, `Enter` ведёт к ячейке в hex, `Esc` — назад.
6. **Сравнение — Проект → Сравнить с файлом** (или перетащить второй `.bin`).
   Отличающиеся байты в hex красные, в 2D вторая прошивка — красная линия,
   `N` / `Shift+N` — к следующему / предыдущему отличию. Вкладка «Отличия»
   показывает затронутые карты (ваши и эталона): сколько ячеек изменено и
   на сколько в единицах карты; или просто блоки байт. В окне карты при
   сравнении есть режимы **текущий / второй файл / разница / %**, изменённые
   ячейки выделены. `⇄` меняет файлы местами.
7. **Проект → Сохранить маппак** как A2L или DAMOS (`Ctrl+S` /
   `Ctrl+Shift+S`). Сохранённый файл открывается обратно как маппак или как
   эталон.
8. **Сверка** — пара ищется по адресу (имя может быть своим). Для каждой пары
   видно, что сходится и что нет: адрес (в том числе «размечено тело без
   заголовка»), вид, размер (в том числе «строки и столбцы перепутаны»),
   ячейка, пересчёт, оси. Пропущенные объекты эталона скрыты, пока не
   попросите.

Маппак автоматически сохраняется в браузере для каждой прошивки (по CRC32).

## Горячие клавиши

| Клавиша | Действие |
|---|---|
| `M` / `W` | больше / меньше столбцов |
| `Tab` | вид: текст → 2D → 3D (и в окне карты тоже) |
| `A` | начинать строки с курсора |
| стрелки, PgUp/PgDn, Home/End | курсор по ячейкам; с Shift — выделение (или тянуть мышью) |
| `K` | новая карта по выделению; на своей карте — свойства |
| `Enter`, двойной щелчок | открыть карту под курсором во вкладке |
| `Esc` | из окна карты — к hex; в hex — снять выделение |
| `Ctrl+A` | выделить карту под курсором |
| `Del` | удалить свою карту |
| `]` / `[` | следующая / предыдущая карта (своя или эталона) |
| `N` / `Shift+N` | следующее / предыдущее отличие от второго файла |
| `G`, `Ctrl+G` | перейти: адрес, `+смещение` в файле или имя карты |
| `Ctrl+F`, `F3` | поиск байтов (`??` — любой) или текста cp1251 |
| `Alt+←` / `Alt+→` | назад / вперёд по переходам |
| `Ctrl+Z` / `Ctrl+Y` | отменить / вернуть |
| `Ctrl+S` / `Ctrl+Shift+S` | сохранить маппак как A2L / DAMOS |
| `Ctrl+O` | открыть прошивку |
| `F1` | все клавиши |

## Связь с WinOLS

Устроено по той же логике, что WinOLS: меню и панель инструментов, окно
карт, карты во вкладках, столбцы `M`/`W`, текст / 2D / 3D, формат ячеек
LoHi/HiLo, свойства карты (размер, знак, множитель, оси), сравнение двух
версий прошивки.
«База» здесь — то же, что смещение при импорте DAMOS/A2L в WinOLS (для C166
обычно 0x800000).

Маппак WinOLS (.kp) — закрытый формат, его приложение не пишет. Мост — A2L:
сохраните маппак как A2L и импортируйте в WinOLS (нужен модуль импорта
DAMOS/A2L, OLS521), указав смещение, равное нашей базе. Импорт нашего A2L в
сам WinOLS не проверялся — WinOLS в разработке не было.

## Соглашения о картах

Строки и столбцы считаются **по памяти**: столбцы — быстрый индекс (соседние
ячейки), строки — медленный. Так сравнение не зависит от того, что в DAMOS и
A2L называется X и Y:

- в DAMOS ось X — это строки, Y — столбцы;
- в A2L при `COLUMN_DIR` быстрее меняется Y, при `ROW_DIR` — X;
- в заголовке Bosch сначала счётчик строк, потом столбцов, затем ось строк и
  ось столбцов; счётчики — слова, только если обе оси словные.

Последние два факта проверены на `px5ns03d.dam` и его образе: порядок
заголовка — на всех неквадратных картах, ширина счётчиков — на всех картах с
заголовком.

Что DAMOS выразить не может (big-endian, float, двумерный блок, другой
порядок заголовка), при сохранении перечисляется в замечаниях, а не
теряется молча.

## Тесты

```
node tests/run.js
```

Синтетическая прошивка с известными картами: запись в A2L и DAMOS и чтение
обратно, сверка (верная, транспонированная, без заголовка), подбор базы.
Если рядом лежит настоящая пара DAMOS + образ (репозиторий Ivanbl4 по
соседству или переменные `DAMOS=… BIN=…`), все её объекты проходят круг
через A2L и через DAMOS: на `px5ns03d.dam` это 2447 из 2447 без расхождений.
