# Mercedes M264 / Bosch MED17.7.7 (TC1793): проект Stage 1

## Идентификация

| Параметр | Значение |
|---|---|
| ЭБУ | Bosch MED17.7.7, Infineon TC1793 rev.2, полный дамп Flash 4 МБ |
| Проект Bosch | `MED41x-18B-SER_045_00-STAR23-x-M26Xxx` (`D177_4A5_18B045S`) |
| Двигатель | M260/M264 (сборка ПО `M260_M264 18B_Star23_VC08`, 20.12.2018) |
| Номера ПО Mercedes | A264 902 41 00, A264 903 12 01, A264 904 04 00 |
| SW Bosch | boot `10SW039623`, ASW `10SW049294`, калибровка `10SW049489` |
| Чтение | через boot, защита RW W0 [00000-1FFFFF], исходник: `original/` |

## Карта памяти (смещения в файле, адрес = 0x80000000 + смещение)

| Смещение | Содержимое |
|---|---|
| `0x000000–0x01FFFF` | Boot (CBOOT/SBOOT), 10SW039623 |
| `0x020000–0x1FFFFF` | ASW, часть 1 (код), 10SW049294 |
| `0x200000–0x21FFFF` | пусто (0x00) |
| `0x220000–0x2BDFFF` | **Калибровка (DS)**, 10SW049489: все карты здесь |
| `0x2C0000–0x3BFFFF` | ASW, часть 2 (код) |
| `0x3C0000–0x3FFFFF` | пусто |

В начале каждого блока стоит стандартный заголовок Bosch с диапазонами
контрольных сумм. **После правки КС нужно пересчитать**: это делают WinOLS
(плагин MED17), Autotuner, Flex, KESS3 или PCMflash при записи. Записывать
лучше тем же способом, каким читали (boot/bench), чтобы проверка подписи
по OBD не помешала.

## Формат карт

Записи Bosch лежат подряд: `[nx:u16][ny:u16][ось X][ось Y][данные]`, все
значения little-endian u16. Данные хранятся по столбцам: быстрее меняется Y.

Шкалы, которые подтвердились:
- обороты: raw × 0.25 об/мин (`26000` = 6500 об/мин);
- нагрузка rl: raw × 0.0234375 % (`10667` = 250 %);
- момент: raw × 100/32768 % (`32768` = 100 %).

`analysis/map_candidates.csv`: 742 карты-кандидата, найденные автоматически
(`tools/mapfinder.py`).

## Опознанные карты

| Адрес | Размер | Карта | Уверенность |
|---|---|---|---|
| `0x23BFEC` | 16×14 | **KFMIOP**: оптимальный момент по rl×n (rl 5–250 %, момент до 110 %) | высокая |
| `0x23C1EC` | 16×14 | **KFMIRL**: заданная нагрузка по моменту×n (обратная к KFMIOP) | высокая |
| `0x280FE2`, `0x2811E2`, `0x2813E2`, `0x2815E2` | 16×14 | копии KFMIOP (по одной на набор данных/режим) | средняя |
| `0x282590` | 16×14 | вероятно ещё одна копия KFMIRL | средняя |
| `0x2690D2 … 0x26A0F6` | 8 × 16×16 | семейство rl×n по 8 вариантам: вероятно зажигание (KFZW/KFZWOP по фазам/цилиндрам) | низкая, проверить |
| `0x26A580`, `0x26AEF0 … 0x26B196` | 15×6 | n × давление (raw × 0.078125 = 1000–2000 гПа): вероятно наддув/дроссель | низкая, проверить |

Полные таблицы KFMIOP/KFMIRL: `analysis/KFMIOP_KFMIRL.txt`.

## План Stage 1 (на штатном катализаторе)

Ориентиры для M264 2.0 (одно железо у C200/E200/C300):
стоковые 184–197 л.с. / 300–320 Нм → Stage 1 ≈ 240–250 л.с. / 370–400 Нм
на АИ-98. На АИ-95 планку лучше снизить на 15–20 Нм.

Что меняется, по порядку:
1. **Ограничители момента Mercedes** (Нм-структура, по передачам и оборотам):
   поднять до 400 Нм. *Пока не найдены, нужен damos/A2L или сравнение со
   стоковым/тюнинговым файлом той же прошивки.*
2. **Максимальная нагрузка / наддув** (LDRXN, предел давления наддува,
   KFLDHBN): +15–20 % rl в зоне 2000–5000 об/мин, предел наддува до
   ~2.0–2.1 бар абс. *Кандидаты в таблице выше, нужна проверка.*
3. **KFMIRL** (`0x23C1EC`): продлить верхние строки так, чтобы при моменте
   100–120 % требовалась нагрузка с запасом. Это нужно согласовать с пунктом 2.
4. **Зажигание**: штатное, корректирует детонационный контроль. По логам
   ретарды не больше 3–4°.
5. **Лямбда защиты компонентов**: обогащение на полной нагрузке до λ 0.82–0.85
   и контроль температуры ОГ по логам.

После прошивки снять логи (обороты, rl заданная/фактическая, давление
наддува заданное/фактическое, УОЗ и ретарды по цилиндрам, лямбда) на 3-й и
4-й передаче в пол.

`tools/patch.py` применяет JSON-рецепт правок и проверяет, что заголовок
карты совпадает:

```json
{"edits": [
  {"name": "KFMIRL +10% from 2000rpm", "addr": "0x23C1EC", "nx": 16, "ny": 14,
   "op": "scale", "value": 1.10, "x_from": 8000}
]}
```

```
python3 tools/patch.py original.bin stage1.json stage1.bin
```

КС после этого корректирует программатор.

## Что не входит в проект

Отключение катализатора, задних лямбда-зондов и перевод на Евро-2 сюда не
входят (см. обсуждение в сессии). Stage 1 делается и работает на штатном
катализаторе.
